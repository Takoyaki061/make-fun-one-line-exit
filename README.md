Entry for the make.fun bounty [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

`main.py` (Python standard library only) writes one one-line resignation
letter to `/output/entry.txt`:

> The animals and I have agreed to a mutual separation—they keep the enclosure, I keep my dignity, and the penguins keep the keys.

The line is a zookeeper's resignation: a formal "mutual separation" that
collapses into absurdity when the penguins end up holding the keys. It reads
like a letter someone could actually send, the punchline lands in the final
clause, and the specific voice (a zookeeper, not a generic quitter) is the
whole joke.

Run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose the
output directory). See `CANDIDATES.md` for the brainstormed candidates and
the critique that picked this line.
